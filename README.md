# Medical Data Analysis: Cardiovascular Risk Factor Evaluation

## 📌 Project Overview
This project presents an exploratory data analysis (EDA) of patient clinical attributes to identify key trends associated with cardiovascular diseases. Cardiovascular disease remains a primary focus of global public health research, and leveraging data-driven approaches allows for early risk estimation and better medical intervention strategies.

---

## 🔬 Key Clinical Parameters
The dataset evaluates the following clinical metrics across various patient age brackets:
- **Age**: Patient age in years.
- **RestingBP**: Resting blood pressure (mmHg).
- **Cholesterol**: Serum cholesterol levels (mg/dL).
- **HeartDisease**: Diagnostic status of heart disease (0 = Normal, 1 = High Risk).

---

## 📊 Analytical Methodology
The analytical pipeline was implemented using **Python (Pandas & Matplotlib)** to perform:
1. Data cleaning and statistical aggregation.
2. Comparative analysis between age groups and serum cholesterol concentration.
3. Visualization of hypertension and lipid profiles relative to diagnosis.
